# ✦ Syncify Studio

> Стильный и автономный инструмент для переноса и умной синхронизации музыки из **Spotify** в **YouTube Music**.

## ⚡ Особенности

- **Без Spotify Premium и API-ключей:** парсит плейлисты любого объема (300+ треков) напрямую без регистрации в Spotify Developer.
- **Умное зеркалирование новинок:** запоминает состояние плейлиста (`Слепок базы`) и добавляет только те треки, которые реально появились позже.
- **Синхронизация удалений:** если удалить трек в Spotify, программа заметит это и аккуратно удалит его из YouTube Music.
- **Fuzzy Matching:** умное нечеткое сопоставление названий — треки с приписками `(Official Video)`, `[Remastered]` или `feat.` не удаляются по ошибке.
- **Батчинг (быстрая заливка):** треки отправляются в YouTube Music пакетами по 25 штук за один запрос без риска поймать `HTTP 429 Too Many Requests`.
- **Встроенные утилиты:**
  - 🧹 Очистка плейлиста YouTube Music от дубликатов в 1 клик.
  - 📋 Список «потеряшек» (треки, которых нет на YouTube).
  - 📥 Скачивание любых выбранных треков в формате MP3 на диск.
- **Интерфейс в стиле Linear & Spotify:** глубокая темная тема, плавные анимации, системные диалоги проводника и работа в виде одиночного `.exe` без черных окон консоли.
- **Автообновления по воздуху:** проверка свежих версий прямо через GitHub Releases.

## 🔑 Авторизация в YouTube Music (занимает 15 секунд)

Для работы со своими плейлистами программе требуется сессионный ключ:

1. Откройте [music.youtube.com](https://music.youtube.com) в браузере под своим Google-аккаунтом.
2. Нажмите клавишу **F12** (Инструменты разработчика) ➔ перейдите на вкладку **Network (Сеть)**.
3. Обновите страницу (**F5**).
4. Кликните по любому запросу к сайту (например, `browse`).
5. В блоке **Request Headers** скопируйте значение строки `Cookie` целиком.
6. В приложении нажмите **«🔑 Авторизация YouTube»**, вставьте скопированное и нажмите **«Сохранить»**.

*Файл сессии сохраняется локально на вашем компьютере и никуда не передается.*
