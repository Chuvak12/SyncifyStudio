## ⚡ Ключевые возможности

### 🔄 Интеллектуальный движок синхронизации
- **Без Spotify Premium и API-ключей:** парсит любые публичные плейлисты (до 2000+ треков) напрямую без регистрации в Spotify Developer.
- **Двустороннее зеркалирование:** программа не только находит свежие новинки, но и замечает, если трек был удален из Spotify, аккуратно убирая его из YouTube Music.
- **Турбо-поиск в 4 потока:** параллельная многопоточная сверка треков (`ThreadPoolExecutor`) ускоряет обработку в 5 раз.
- **Персистентный кэш поиска:** найденные соответствия сохраняются в локальную базу. Повторная сверка треков происходит за доли секунды без лишних сетевых запросов.
- **Батчинг (пакетная заливка):** треки добавляются в плейлист пачками по 25 штук за один запрос — никаких зависаний и риска получить бан `HTTP 429`.
- **Fuzzy Matching:** алгоритм нечеткого сопоставления строк защищает от ложных удалений треков с приписками `(Official Video)`, `[Remastered]` или `feat.`.

### 🎨 Дизайн и удобство (Linear x Spotify x Telegram)
- **Адаптивная Flex-верстка:** список треков динамически масштабируется на весь экран монитора с плавной частотой 60 FPS.
- **4 цветовые темы:** переключение между *Spotify Green*, *Linear Indigo*, *Cyberpunk Amber* и *Electric Cyan* в один клик.
- **Живой прогресс-бар:** наглядная шкала выполнения от 0% до 100% с кнопкой моментальной безопасной отмены.
- **Умный буфер обмена:** автоматическое определение ссылки на Spotify при открытии программы.
- **Мини-аналитика плейлиста:** карточка со статистикой (общее число треков, количество уникальных артистов и топ-3 исполнителей).
- **Быстрый переход `[ ↗ ]`:** открытие плейлистов в браузере в один клик прямо из полей ввода.

### 🛠️ Встроенный арсенал
- **🧹 Чистка дубликатов:** поиск и удаление случайных повторов в плейлисте YouTube Music в 1 клик.
- **📋 Список «потеряшек»:** реестр редких треков, которые не удалось отыскать на YouTube, с возможностью копирования в буфер.
- **📥 Скачивание в MP3:** прямой загрузчик треков на жесткий диск или флешку через встроенный модуль `yt-dlp`.

### 💻 Системная интеграция Windows
- **Автозапуск:** опция тихого старта вместе с Windows через реестр (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).
- **Сворачивание в трей:** работа в фоне возле системных часов с меню быстрого синхрона по правому клику.
- **Всплывающие уведомления:** нативные тосты Windows по завершении длинных операций с возможностью полного отключения в настройках.
- **Безопасность Local-First:** все настройки и кэши хранятся в системной папке `%APPDATA%\SyncifyStudio` с атомарной защитой файлов от сбоев питания.
- **Автообновления:** проверка свежих релизов напрямую через GitHub Releases.

## 🔑 Авторизация в YouTube Music (занимает 15 секунд)

Для управления вашими плейлистами программе требуется локальный сессионный ключ:

1. Откройте [music.youtube.com](https://music.youtube.com) в браузере под своим Google-аккаунтом.
2. Нажмите клавишу **F12** (Инструменты разработчика) ➔ перейдите на вкладку **Network (Сеть)**.
3. Обновите страницу (**F5**).
4. Кликните по любому запросу к сайту (например, `browse`).
5. В блоке **Request Headers** найдите строку `Cookie` и скопируйте её значение целиком.
6. В приложении нажмите **«🔑 Авторизация YouTube»**, вставьте строку и нажмите **«Сохранить»**.

> 🔒 *Ключ авторизации сохраняется исключительно на вашем локальном компьютере (`%APPDATA%/SyncifyStudio/browser.json`) и никогда не передается третьим лицам.*

## ⚙️ Структура проекта (Для разработчиков)

Проект разделен на независимые модули:

```text
SyncifyStudio/
├── app.py              # Точка входа, жизненный цикл окна и системный трей
├── config.py           # Хранилище %APPDATA%, реестр Windows, конфиги
├── auth.py             # Валидация Google Cookie и генерация SAPISIDHASH
├── sync_engine.py      # Многопоточный поиск, Fuzzy Matching, кэш и батчинг
├── ui.py               # Responsive HTML5/CSS/JS интерфейс и темы
├── Собрать.bat         # Скрипт быстрой компиляции в .exe через PyInstaller
├── requirements.txt    # Зависимости Python
├── .gitignore          # Защита конфиденциальных файлов сессий
└── README.md           # Документация проекта
```

### Запуск из исходного кода:

```bash
# Клонирование репозитория
git clone https://github.com/Chuvak12/SyncifyStudio.git
cd SyncifyStudio

# Установка зависимостей
pip install -r requirements.txt

# Запуск приложения
python app.py
```

### Сборка автономного `.exe`:
Просто запустите файл **`Собрать.bat`** — он очистит старые кэши и скомпилирует приложение с вашей иконкой `icon.ico` в один исполняемый файл.

## 🛡️ Безопасность и конфиденциальность

- Программа не требует ввода паролей от аккаунтов.
- Работает без внешних промежуточных серверов: все запросы идут напрямую `Ваш ПК ➔ Spotify` и `Ваш ПК ➔ Google`.
- Чувствительные данные (`browser.json`, ссылки на плейлисты) защищены правилами `.gitignore` и не попадут в публичный репозиторий.
